# 解析器子元素挂载下沉专项设计

> 2026-08 定稿并已实施（双栈 ctest 18/18）。缘起 `doc/土法编程审阅.md` #2。
> 目标：把"元素如何接收子元素、接收后如何校验"从 parser 的运行时类型识别
> 下沉为元素自身的虚函数职责，工厂改查表；新增部件的 parser 改动面降为零。

## 1. 问题（现状证据）

`src/parser/XmlLayoutParser.cpp::parseNode`（175-284，110 行）混了四类职责：

1. 工厂：`createElement`（136-166）9 标签 if-else 字符串链；
2. 子元素挂载：198-203 六连 `dynamic_pointer_cast`，随后四个类型分支
   （column/row/grid 收 N 个、cell 收第一个、for 收模板、if 收孩子）；
3. 类型专属校验：grid 的 BI-P-008/009、if 的 BI-P-010 内联在 parser；
4. 伪属性包装（`b:of`/`b:prop` 隐式 `<for>`/`<if>`）——真 parser 职责，保留。

新增部件当前要改 6 处：工厂链 + cast 链 + 挂载分支 + 校验分支 + XSD + include。

**附带发现的现状 bug**：cell/for/if 分支只读 `firstChildElement()`，
多写的子元素被**静默吞掉**，无诊断（见 §5 待裁决点 1）。

## 2. 设计

两个新虚函数构成"解析期挂载协议"，工厂改静态表。parseNode 只剩直线流程。

### 2.1 Element 基类新增（`include/broaditem/element/Element.h`）

```cpp
    /// @brief 挂载一个解析完成的模板子元素（解析期由 XmlLayoutParser 逐个子元素调用）。
    ///
    /// 默认实现忽略（叶子元素走不到这里：canHaveChildren() 为 false 且含子元素时
    /// 已由 parser 报 BI-P-007）。容器类按自身语义接收：多子容器追加；
    /// 单子元素类型（cell/for/if）保留第一个、忽略多余。
    /// @param child 解析完成的子元素。
    virtual void addParsedChild(const ElementPtr& child);

    /// @brief 子元素挂载完成后的解析期收尾校验。
    ///
    /// 默认通过。需要做结构校验的类型在此覆盖（grid 的 cell 计数、if 的条件存在性），
    /// 失败时报诊断并返回 false，parser 按子树解析失败处理。
    /// @return 校验通过返回 true。
    virtual bool validateChildren() const;
```

默认实现（`src/element/Element.cpp`）：

```cpp
void Element::addParsedChild(const ElementPtr& child)
{
    Q_UNUSED(child)  // 叶子/无关类型忽略；见头文件契约
}

bool Element::validateChildren() const
{
    return true;
}
```

### 2.2 各类型覆盖

```cpp
// MultiChildContainer（column/row/grid 共用，三分支合一）
void MultiChildContainer::addParsedChild(const ElementPtr& child)
{
    addChild(child);   // 既有 mutator 复用
}

// CellElement：保留第一个，多余忽略（与现状行为一致，见 §5 待裁决点 1）
void CellElement::addParsedChild(const ElementPtr& child)
{
    if (!content())        // ContainerElement 既有访问器
        setContent(child);
}

// ForElement / IfElement 同理：保留第一个
void ForElement::addParsedChild(const ElementPtr& child)
{
    if (!m_template)
        setTemplate(child);
}
void IfElement::addParsedChild(const ElementPtr& child)
{
    if (!m_child)
        setChild(child);
}

// GridLayout：BI-P-008/009 从 parser 迁入（保留一处 dynamic_cast 判定 cell，
// 局限在 GridLayout 内部，不外溢）
bool GridLayout::validateChildren() const
{
    int cellCount = 0;
    for (const auto& child : m_children) {
        if (std::dynamic_pointer_cast<CellElement>(child)) {
            cellCount++;
        } else {
            Diagnostics::reportParse(ErrorCode::GridNonCellChild,
                                     QStringLiteral("GridLayout: child must be <cell>"));
            return false;
        }
    }
    const int expected = m_columns * m_rows;
    if (cellCount != expected) {
        Diagnostics::reportParse(ErrorCode::GridCellCountMismatch,
                                 QStringLiteral("GridLayout: expected %1 cells (%2x%3), got %4")
                                     .arg(expected).arg(m_columns).arg(m_rows).arg(cellCount));
        return false;
    }
    return true;
}

// IfElement：BI-P-010 从 parser 迁入
bool IfElement::validateChildren() const
{
    if (!isConditionValid()) {
        Diagnostics::reportParse(ErrorCode::IfMissingProp,
                                 QStringLiteral("<if> requires b:prop to specify the condition path"));
        return false;
    }
    return true;
}
```

### 2.4 收敛后的 parseNode（全文）

```cpp
ElementPtr XmlLayoutParser::parseNode(const QDomElement& xml)
{
    const SegmentGuard guard(segmentFor(xml));
    const QString tag = xml.tagName();

    bool wrapFor = xml.hasAttributeNS(BINDING_NS, "of") && tag != QLatin1String("for") && tag != QLatin1String("if");
    bool wrapIf = xml.hasAttributeNS(BINDING_NS, "prop") && tag != QLatin1String("for") && tag != QLatin1String("if");

    ElementPtr element = createElement(tag);
    if (!element)
        return nullptr;

    element->parse(xml);
    // parseBindings 对控制元素同样调用；保留名豁免在 parseBindings 内部
    element->parseBindings(xml);

    if (!element->canHaveChildren() && !xml.firstChildElement().isNull()) {
        Diagnostics::reportParse(ErrorCode::LeafWithChildren,
                                 QStringLiteral("<%1> should not have child elements").arg(tag));
        return nullptr;
    }

    // 挂载语义在各元素的 addParsedChild 中
    for (QDomElement child = xml.firstChildElement(); !child.isNull(); child = child.nextSiblingElement()) {
        auto childEl = parseNode(child);
        if (childEl)
            element->addParsedChild(childEl);
    }

    // 结构校验在各元素的 validateChildren 中
    if (!element->validateChildren())
        return nullptr;

    // ---- 以下为 parser 本职，原样保留 ----
    if (wrapFor) { ... }          // 隐式 <for> 包装（不变）
    if (wrapIf) { ... }           // 隐式 <if> 包装（不变）
    if (tag != "for" && hasAttributeNS("as") && !hasAttributeNS("of")) ...  // BI-P-018（不变）

    return element;
}
```

## 3. 行为不变量

- 诊断错误码、消息文案、触发条件全部不变（BI-P-005/006/007/008/009/010/018）；
- 挂载顺序不变（先挂子、后校验；if 的校验从"挂子前"移到"挂子后"，失败均丢弃整棵子树，外部不可观察）；
- cell/for/if 多子元素"保留第一个"的现状行为本轮保持不变（§5 待裁决点 1）；
- deprecated 装饰器与未知标签分支不变；
- 模板/控制元素物化语义（materializeChildren 体系）不涉及。
